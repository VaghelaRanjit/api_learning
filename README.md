# API Learning App 🚀

A Flutter application for learning and practicing API integration in Flutter.

## Features
- Fetch API data
- Display API response in UI
- Loading indicators
- Error handling
- Clean UI
- REST API integration

## Tech Stack
- Flutter
- Dart
- HTTP Package / Dio
- GetX
