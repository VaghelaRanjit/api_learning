# API Learning App 🚀

A Flutter application for learning and practicing API integration in Flutter with model and without model

## Features
- Fetch API data
- Display API response in UI
- Loading indicators
- Error handling
- Clean UI
- REST API integration

## Tech Stack
- Flutter
- Dart
- HTTP Package 
- GetX

## Getting Started

### Clone Repository
git clone https://github.com/VaghelaRanjit/api_learning.git

### Install Dependencies
flutter pub get

### Run Project
flutter run
